Skrip MikroTik siap tempel, tanpa ngetik ulang

Isi form, pilih RouterOS v6 atau v7, lalu salin atau unduh file .rsc. Dibuat untuk kebutuhan RT/RW net: PPPoE pelanggan, voucher hotspot, load balance, sampai firewall.

Buka generatorCara pakai 
# ===== PPPOE SERVER =====
/ip pool add name=pool-pppoe ranges=10.10.10.2-10.10.10.254
/ppp profile add name=PAKET-10M local-address=10.10.10.1 \
    remote-address=pool-pppoe rate-limit=10M/10M only-one=yes
/interface pppoe-server server add service-name=pppoe-rtrw \
    interface=ether4 default-profile=PAKET-10M disabled=no
# akun pelanggan
/ppp secret add name="plg001" password="k7m2xq9a" profile=PAKET-10M
/ppp secret add name="plg002" password="r4tz8np3" profile=PAKET-10M
# ===== FIREWALL =====
/ip firewall filter add chain=input action=drop \
    in-interface-list=WAN protocol=udp dst-port=53

Sembilan modul, satu skrip

Nyalakan modul yang dibutuhkan saja. Semua digabung jadi satu skrip berurutan dengan komentar per bagian.

DasarIdentity, NTP, WAN DHCP/statis/PPPoE client, bridge LAN, DHCP server, DNS, NAT.
IP AddressTambah IP ke ether, bridge atau VLAN dengan pilihan interface.
IP RouteRoute statis lengkap: dst-address, gateway, distance, check-gateway, routing table.
PPPoE ServerProfil paket dengan rate-limit, akun pelanggan massal, profil isolir dan redirect halaman.
HotspotServer hotspot, profil user, voucher acak dengan limit-uptime.
Load BalancePCC, NTH atau ECMP. Dua WAN atau lebih, bobot per ISP, failover otomatis.
FirewallTutup input dari WAN, blok open resolver DNS, matikan layanan tak terpakai.
VLANBanyak VLAN sekaligus, lengkap dengan IP, pool dan DHCP server.
Simple QueueLimit per IP atau subnet, dengan queue induk TOTAL bila perlu.

Tiga langkah

Dari form sampai jalan di router.

Isi formSesuaikan nama interface, IP dan paket dengan router Anda.
Cek peringatanKotak merah menandai isian salah atau pengaturan yang berisiko.
Tempel atau importSalin ke Terminal Winbox, atau unduh .rsc lalu jalankan /import.
