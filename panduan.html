Panduan memakai skrip

Skrip hasil generator adalah perintah RouterOS biasa. Ada dua cara menjalankannya, dan satu kebiasaan yang wajib: backup dulu.

BackupLewat terminalImport .rscCatatan modulv6 dan v7

1. Backup konfigurasi lama

Simpan konfigurasi sekarang sebelum menjalankan skrip apa pun, supaya bisa kembali kalau ada yang salah.

/export file=backup-awal
/system backup save name=backup-awal

File backup-awal.rsc dan backup-awal.backup muncul di menu Files. Unduh keduanya ke komputer.

2. Jalankan lewat Terminal Winbox

Tekan Salin skrip di generator, buka Winbox, klik New Terminal, lalu klik kanan dan pilih Paste. Baris diawali # hanya komentar dan diabaikan router.

Tempelan sampai sekitar 200 baris umumnya lancar. Untuk skrip lebih panjang (ratusan akun atau voucher), pakai cara import di bawah karena tempelan besar bisa tersendat, terutama lewat aplikasi SSH ponsel atau WebFig. Tombol Salin di tiap bagian memudahkan menempel per modul.
Safe Mode: sebelum menjalankan modul Firewall, tekan tombol Safe Mode di Winbox atau Ctrl+X di terminal. Jika koneksi Anda terputus karena rule baru, router membatalkan semua perubahan secara otomatis. Tekan lagi untuk menyimpan setelah semuanya aman.

3. Import file .rsc

Tekan Unduh .rsc, lalu seret file ke jendela Files di Winbox. Setelah itu jalankan:

/import file-name=Router-RTRW-v7.rsc verbose=yes

Dengan verbose=yes, router menampilkan baris yang gagal sehingga mudah dicek.

Mode aman (aktif bawaan) membungkus perintah add dengan :do { ... } on-error={ ... }. Jika pool, profil, bridge atau akun dengan nama sama sudah ada di router, baris itu dilewati dan muncul pesan dilewati (sudah ada), sehingga import tidak berhenti di tengah. Rule firewall tidak dibungkus, jadi jangan jalankan modul Firewall dua kali.

4. Catatan per modul

  • Dasar: kalau port LAN sudah masuk bridge bawaan, hapus dulu dari bridge lama di Bridge → Ports, atau perintah /interface bridge port add akan gagal.
  • PPPoE Server: tombol Unduh daftar akun (.csv) menyimpan username dan password pelanggan, bisa dibuka di Excel atau diimpor ke billing. rule filter ISOLIR ditambahkan di urutan bawah. Pindahkan ke atas rule forward lain di IP → Firewall → Filter agar efektif. Untuk mengisolir pelanggan, ganti profil secret-nya ke ISOLIR lalu putus sesinya di PPP → Active.
  • Hotspot: interface hotspot sebaiknya tidak menjadi anggota bridge LAN. Tombol Cetak kartu voucher membuka halaman siap cetak, 4 kartu per baris. Tombol Unduh voucher (.csv) menyimpan daftar kode untuk arsip.
  • Load Balance: ada tiga metode. PCC membagi per koneksi berdasarkan alamat dan port, paling stabil untuk RT/RW. NTH membagi koneksi baru bergiliran, rata tapi situs yang butuh IP tetap (bank, game) bisa terputus. ECMP cukup memakai route multi-gateway, paling sederhana dan ringan. gateway tiap WAN harus berupa IP. Jika WAN modul Dasar ikut di-balance, default route dan NAT-nya otomatis diserahkan ke modul Load Balance.
  • Firewall: opsi drop input dari WAN menutup Winbox dari internet. Pastikan Anda masuk lewat LAN, VPN atau tunnel sebelum menjalankan. FastTrack membuat rate-limit PPPoE dan queue tidak jalan.

5. Bedanya v6 dan v7

Pilih versi sesuai router. Cek dengan /system resource print. Perbedaan yang ditangani generator:

  • Load balance: v7 membuat /routing table dan memakai routing-table=; v6 memakai routing-mark=.
  • NTP client: v7 memakai servers=; v6 memakai primary-ntp=.
  • FastTrack: v7 menambahkan hw-offload=yes.
